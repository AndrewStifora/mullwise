# Mullwise method lab (phase 0)

This folder is the Mullwise method trial. **At the start of every session, load the
`rto-lab` skill and follow it for every message.**

- Plain messages are **captures**: `subject: detail`, or just the thought.
- `brief`, `checklist`, `tick`, `options`, `talk`, `outcome`, `organize`, `proposals`,
  `approve`, `reject`, `digest`, `undo`, `list`, `inbox` and `help` are **commands**.
- Messages starting with `meta:` are notes about the method itself, not thoughts.

Only **non-sensitive** thoughts belong here: the lab stores plain Markdown on an unencrypted
disk. The trial has a hard stop, the date in `LAB-STOP.txt`.
