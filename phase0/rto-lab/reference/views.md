# Recall view templates

Keep views glanceable. Use the user's own words for their items. Mark suggestions with
*(suggested)*. Never include content from other subjects except in the **Related** line.

## Brief (≤ 12 lines)

```
**Q3 budget** · topic · 6 thoughts · 3 open · updated today
One line: <what this subject is about, in the user's terms>
Must-cover:
 1. Ask Sam about the Q3 timeline
 2. Number before the offsite
 3. Send the draft to Priya
Questions: What if it slips past October? (suggested)
Decision pending: delay the hire to Q4? (2 options)
Related: Sam Okafor (both mention the timeline) · Offsite plan
```

## Checklist

```
**Q3 budget**: open items
Q 1. [ ] Ask Sam about the Q3 timeline
T 2. [ ] Send the draft to Priya
P 3. [ ] Make sure I say hiring can wait
Reply "tick 2", "tick draft", or "tick all Q".
```

## Options / decision tree

```
**Delay the hire?** · decision
Options
 A. Delay to Q4: saves cash / slows launch
 B. Hire now: faster launch / tight budget
If-then
 - If revenue beats plan → B
 - If the Q3 timeline slips → A, revisit in November (suggested)
Fallback: contractor for 3 months (suggested)
```

## Talk mode (use during the conversation)

```
**1:1 with Sam Okafor** · talk mode
Goal: agree the Q3 timeline
MUST SAY
 1. Hiring can wait
 2. Need a number before the offsite
ASK
 3. When is the realistic Q3 date?
IF THEY SAY
 - "Not before November" → propose the contractor option
AFTER: reply "outcome" to capture what was agreed
```

## Outcome capture

Ask three short questions in one message: **agreed**, **still open**, **follow-ups**. Then:
- append a line to `## Outcome`
- tick the items that were covered
- copy the still-open items to the person's subject as open items (`mine`)
- log the batch
